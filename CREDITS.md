# Credits and Acknowledgments

This project is made possible thanks to the following open-source libraries, databases, and creative assets.

## Third-Party Libraries
*   **[Dear ImGui](https://github.com/ocornut/imgui):** Bloat-free Graphical User interface for C++ with minimal dependencies.
*   **[Assimp](https://github.com/assimp/assimp):** Open Asset Import Library for loading various 3D model formats.
*   **[GLM](https://github.com/g-truc/glm):** OpenGL Mathematics library for 3D software based on the OpenGL Shading Language (GLSL) specifications.
*   **[spdlog](https://github.com/gabime/spdlog):** Very fast, header-only/compiled, C++ logging library.

## Submodules & Databases
*   **[Assimp-Model-Database](https://github.com/assimp/assimp-mdb):** Included as a Git submodule for testing various 3D model formats. Created by Kim Kulling (Spider-Wavefront) and the Asset-Importer-Library contributors.
